# CLI reference

## `transit-audit audit`

Run checks and metrics, writing `results.json`, `report.html`, `backlog.json`, and `backlog.csv`.

## `transit-audit validate`

Ingest MobilityData `report.json` or invoke the pinned validator when Java is available.

## `transit-audit checks list`

Print check/metric IDs and source URLs.

## `transit-audit report`

Render HTML from an existing `results.json`.
