## Claim ceiling

Production ranking supplies best-case reductions among evaluated fields on the sampled OD set; it supplies neither a global-top guarantee over skipped fields nor an expected value without outcome probabilities. Schedule bounds do not adjudicate real-world wheelchair journeys. Memory observations are non-atomic samples, can miss transient peaks, and cannot certify a hard process-tree cap. Live memory collection is unavailable in this sandbox; the record explicitly says the stop could not be enforced. Java heap reserves allocate budget but do not guarantee native-memory overhead. Hardware/platform fields report availability rather than assume a machine model. See [publication correction](../amendments/AMENDMENT_2026-10-01_06_publication.md), [GTFS semantics](https://gtfs.org/documentation/schedule/reference/), [Java heap options](https://docs.oracle.com/en/java/javase/21/docs/specs/man/java.html) and [Python process behavior](https://docs.python.org/3/library/subprocess.html).

Retained public inputs remain the publishers' information. The README ownership paragraph now points to their licences rather than asserting ownership of all repository contents. Snapshot retrieval is through the repository tree or local bundle containing the verified digest-named files; an externally published immutable archive is not claimed.
